A small, collapsible corner summary of how much of the plan's daily target its meals add up to so far, and how much is left — asked for directly. Starts minimized (just the toggle button) rather than expanded: found live that the expanded table, fixed to the bottom-right corner, is wide enough on a phone-sized viewport to cover the "+ Add item" button of whichever meal card happens to sit behind it — a small floating box that already covers what it's meant to help with isn't actually small. Expand/minimize state lives in Alpine's own per-widget data rather than being persisted, since re-collapsing it on the next page load costs nothing. Two columns, not three — a first version had a separate "Left" table column alongside "So far," which overflowed the widget's own narrow fixed width in several languages (found live in Finnish: "Hiilihydraatit" alone is wider than this box's whole first-column budget). "So far / target" reuses diary_day.html's own already-proven two-column "X / Y unit" row shape (`services.daily_totals`); "left" moves to one wrapping text line below the table instead of a third column, since flowing text can wrap onto a second line in a narrow box without looking broken the way a clipped table header does. {% endcomment %}
