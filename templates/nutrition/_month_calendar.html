Every month-changing link below is HTMX (hx-get + hx-target="#month- calendar" + hx-swap="outerHTML"), not a plain , so switching months swaps just this one card instead of a full-page navigation — found needed live: every click used to reload and repaint the entire dashboard for a one-card change, visible as a brief flash each time. `href` stays set on every link regardless (a normal, working page navigation) — HTMX only intercepts the click, so this degrades correctly if JS is ever unavailable. `hx-push-url="true"` keeps the address bar's own `?month=` in sync either way, so reloading, sharing, or using the browser's own back/forward buttons all still land on the right month. DashboardView.get_template_names() renders just this partial for the HTMX request that results (never the whole dashboard again), and outerHTML swaps the whole card including the `x-data` below — Alpine only reads `calendar-days-data`'s contents once, at `x-data` init, so the *element* has to be replaced wholesale for a new month's popover data to ever take effect, not just its inner content. {% endcomment %} {{ calendar_days_json|json_script:"calendar-days-data" }}
