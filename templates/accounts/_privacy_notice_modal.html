{% load i18n %} {% comment %} A fixed, translated privacy notice (unlike registration/ _auth_disclaimer.html's SiteDisclaimer, which is free-form operator- authored text) — shown from the login/signup pages (at the point data collection actually starts) and from the profile page (so it's not a one-time thing you can only ever see once, before you had an account to look back at it from). Included wherever it's needed rather than put in base.html directly: unlike the changelog modal, this has nothing to show on every single page, only the couple of places a user is likely to actually want it. IronStack is self-hosted, open-source software, not a company running a service — whoever installs and operates a given instance is the GDPR "data controller" for it, not this project's authors. The notice below says so plainly rather than pretending otherwise. {% endcomment %}
