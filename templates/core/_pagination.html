{% comment %} Shared previous/next pager for any paginated list. Keeps every other GET parameter (search, filters, sort) via `query_string`, url-encoded — built by core_extras' `url_replace`, so it never emits empty `q=` params. Usage: {% include "core/_pagination.html" %} (uses page_obj + request) Optional, for a page with more than one pager or one that should keep its scroll position: `page` (a Page, default page_obj), `param` (its query parameter, default "page"), `anchor` (an id put on the nav and appended to both links, so a full page load lands back on the pager), `label` (aria-label, default "Pagination"), `hx_target` (an element id: the links then swap just that element via HTMX — same URL, `hx-select` picks it out of the full page — so page-level client state such as a selected meal survives; without JS they stay plain links). {% endcomment %} {% comment %} `page_obj` is only looked up when no `page` was passed: a missing variable in a filter argument (page|default:page_obj) raises instead of rendering empty. {% endcomment %} {% if page %} {% include "core/_pagination_nav.html" with pager=page param_name=param|default:"page" %} {% else %} {% include "core/_pagination_nav.html" with pager=page_obj param_name=param|default:"page" %} {% endif %}
