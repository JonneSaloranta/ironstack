{% load i18n l10n %} {% comment %} Single-metric bar chart (category comparison), shared across apps.analytics. One color for every bar: the x-axis labels already carry category identity via the table below, so a categorical hue per bar would just be noise (see dataviz skill "color-formula" — categorical color is for distinguishing overlapping series, not restating what a label already says). Each bar's own category name is drawn directly under it (rotated, so an unbounded number of categories — weeks, muscle groups — doesn't force truncation as aggressively as horizontal text would) — a chart with same-colored, unlabeled bars isn't readable at a glance. The table below still carries the exact figures for anyone who needs precision or a screen reader, and the hover tooltip's figures are never the only way to reach them either. Expects: chart (apps.core.charts.BarSeries), chart_title, unit_label. {% endcomment %}
