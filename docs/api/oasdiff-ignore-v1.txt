Breaking changes to API v1 accepted on purpose (docs/API.md "Versioning").
CI's api-compatibility job passes this file to oasdiff as --err-ignore.
A line matches one change when its first token starting with a slash is the
change's path and it contains the method, path and oasdiff's exact text
(copy them from oasdiff's output). Lines that match nothing are ignored, so
an entry can stay until it is pruned. The job compares with master, so
entries are only needed until the change is released - prune them then.
